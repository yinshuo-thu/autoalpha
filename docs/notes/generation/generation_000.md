## 2) 可复用的正向经验（候选，不等于已验证有效）

尽管未通过，以下机制设计思路仍可保留并简化重测：

### 2.1 值得继续的市场机制
- **价格位置 + K线实体结构**：  
  用 `close` 在区间位置（接近 high/low）结合实体大小，刻画“漂移/衰竭”微结构。
- **成交笔数与成交额的错配**：  
  `trade_count` 与 `dvolume` 的相对变化可作为“参与广度 vs 资金强度”的代理变量。
- **VWAP 锚定行为**：  
  `close-vwap` 及其连续性（含 lag）可表达“突破后是否站稳”的行为特征。

### 2.2 字段组合建议保留
- `close_trade_px, high_trade_px, low_trade_px, open_trade_px, vwap`
- `trade_count, dvolume`
- 组合原则：**价格结构 + 参与度（至少一个量能字段）**，避免纯价或纯量单侧。

### 2.3 平滑/归一化可延续（但需降复杂度）
- `cs_zscore` 仍可作为跨截面对齐基线；
- `ts_mean / ts_ema / ts_decay_linear` 可保留，但建议**只保留1层主平滑**，避免过度嵌套造成噪声放大与高换手。

## 3) 明确负向经验与规避方案

### 3.1 TVR 过高（本代最高约 190.95）
**问题**：换手极高，策略不可交易或成本吞噬。  
**规避**：
- 降低短窗激进信号占比（如减少超短差分/突破触发）；
- 信号输出端增加低频约束：更长主窗口（如 8–20）+ 单层 EMA/Decay；
- 减少“多门控 sigmoid + 多差分”结构，避免每根bar剧烈翻转。

### 3.2 IR 不稳/显著为负（IR = -4.88）
**问题**：风险调整后收益方向错误且稳定性差。  
**规避**：
- 每个新机制先做**方向预检**（不加 `neg` 与加 `neg` 两版都测）；
- 先单机制验证，再叠加量能门控，避免一次性多假设耦合。

### 3.3 IC 方向错误（IC = -0.976）
**问题**：核心经济含义可能与目标收益方向相反。  
**规避**：
- 强制执行“方向消歧模板”：  
  同一公式同时生成 `raw` 与 `neg(raw)`，择优保留；
- 避免未经验证就默认“反转”或“延续”叙事。

### 3.4 结构重复度偏高
**问题**：两条都集中在“价格结构 + trade_count + dvolume + sigmoid 门控 + zscore + 平滑”，多样性不足。  
**规避**：
- 下一代分桶采样机制：  
  `反转`、`延续`、`VWAP偏离回归`、`量价背离` 各至少1条；
- 控制同构：相同核心字段组不超过总候选的 40%。

### 3.5 DSL 语法问题（出现 invalid_formula）
**问题**：至少1条因语法/函数签名不合法直接失效。  
**规避**：
- 生成后先做**语法白名单检查**（函数名、参数个数、括号匹配）；
- 禁用不确定参数个数的写法，统一二元/固定参数模板；
- 限制表达式深度（建议 ≤4 层嵌套）以降低解析失败率。

## 4) 下一代探索启示（可执行约束，7条）

1. **先可解析再优化**：所有公式先过 DSL lint（函数签名+括号+字段合法）。  
2. **强制方向双版本**：每个候选输出 `f` 与 `neg(f)`，先看 IC 符号再进入下一轮。  
3. **换手硬约束**：生成阶段即约束目标 TVR（如 `<80`），超阈值结构直接降权。  
4. **降复杂度**：单公式最多 1 个门控函数（sigmoid/clip 二选一），平滑算子最多 1 层。  
5. **窗口规范化**：主窗口集中在 5–20，避免 2–3 这类高噪声超短窗主导。  
6. **机制分桶采样**：反转/延续/VWAP锚定/量价背离四类均衡生成，防止同质化。  
7. **字段最小完备集**：价格锚（close/vwap/high-low）+ 参与度（trade_count 或 dvolume）各至少一个，避免过拟合堆料。
